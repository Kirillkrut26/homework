# Проект по работе с товарами и категориями

## Описание проекта

Проект на Python для работы с товарами и категориями товаров с использованием объектно-ориентированного программирования (ООП).

## Реализованный функционал

**Класс Product:**
- Хранит название товара.
- Хранит описание товара.
- Хранит цену и количество товара.

**Класс Category:**
- Хранит название и описание категории.
- Содержит список товаров, относящихся к категории.
- Подсчитывает общее количество созданных категорий.
- Подсчитывает общее количество товаров в созданных категориях.
