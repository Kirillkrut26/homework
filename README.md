## Реализованный функционал

**Абстрактный класс BaseProduct:**
* Задаёт базовую структуру и обязательные методы (`__init__`, `price`) для всех товаров магазина.

**Класс-миксин PrintMixin:**
* Выводит в консоль информацию о созданном объекте товара с его параметрами при инициализации (`__repr__`, `__init__`).

**Класс Product (наследник BaseProduct и PrintMixin):**
* Хранит название, описание, цену и количество товара.
* Поддерживает строковое отображение информации о товаре (`__str__`).
* Позволяет складывать товары одного класса для подсчёта их общей стоимости на складе (`__add__`).

**Класс Smartphone (наследник Product):**
* Дополняет базовый товар характеристиками производительности, модели, объёма памяти и цвета.

**Класс LawnGrass (наследник Product):**
* Дополняет базовый товар характеристиками страны-производителя, срока прорастания и цвета.

**Класс Category:**
* Хранит название, описание и приватный список товаров категории.
* Безопасно добавляет в список только объекты `Product` и его наследников (`add_product`).
* Поддерживает строковое отображение названия категории и общего количества товаров на складе (`__str__`).
* Подсчитывает общее количество созданных категорий и уникальных товаров.

**Класс CategoryIterator:**
* Позволяет перебирать товары конкретной категории в цикле `for`.
